# 商品レビュー（ProductRating）

## はじめに

このプラグインを使うと、GP247 のショッピングサイトでお客様が商品に評価をつけ、
レビューを書けるようになります。また、ショップオーナーであるあなたには、それらの
レビューを審査し、返信するためのツールが用意されます。本書はショップ管理者向けの
資料です（プログラミングの知識は不要です）。最後の部分には、テーマ制作者と開発者
向けの説明を追加しています。読み終えると、プラグインをインストールでき、何をオン・
オフできるかを理解し、誰がレビューに対して何をできるかがわかります。

## 主な機能

- お客様は**ログインしないと**レビューできません。
- **購入済みのお客様のみ**レビューできるか、誰でもレビューできるかを選べます。
- 新しいレビューを表示前に**審査が必要**にするか、すぐに表示するかを選べます。
- お客様に**写真の添付**を許可できます（オン・オフ、枚数の上限あり）。
- 評価は **5 つ星または 10 つ星**のスケールです。
- **レビュー審査**画面と**ショップ別の統計**画面があります。
- 各レビューの下に**公開返信**ができます。
- お客様は自分のレビューを**自分で編集・取り下げ**できます。
- **マルチベンダーのマーケットプレイス**（MultiVendor プラグイン）では、各ショップが
  自分の販売する商品のレビューに返信でき、返信にはそのショップ名が表示されます。

## インストール

1. 管理画面にログインし、**Plugins** メニューを開きます。

2. **Product Rating & Review** の行を探し、**インストール**（Install）ボタンをクリックします。

   成功すると、インストール完了のメッセージが表示され、プラグインは有効な状態に
   切り替わります。

3. **ターミナル**（Windows では「コマンドプロンプト」）を開き、Web サイトのフォルダに
   移動してから、次の 1 行をそのまま入力して Enter キーを押します。

   ```
   php artisan optimize:clear
   ```

   この手順でキャッシュが消去され、Web サイトが新しい画面を認識します。省略すると、
   メニューをクリックしたときに「ページが見つかりません」というエラーになることが
   あります。これはプラグインのインストール後に最もよく起きるエラーです。

4. 確認：管理画面に次の 2 つの新しいメニュー項目が表示されます。

   - **Catalog → 商品レビュー**（レビューを審査する場所）
   - **Report → レビュー統計**（数値を確認する場所）

5. ストアフロントで任意の商品ページを開き、説明文の下までスクロールします。
   **「商品レビュー」**ブロックが表示されます。テーマを編集する必要はありません。

アンインストールすると、プラグインはレビューデータと上記 2 つのメニュー項目を自動的に削除します。

### コマンドラインでのインストール（CLI、gp247 3.x）

gp247 3.x 以降は、管理画面を開かずに、GP247 ライブラリから **ProductRating** をダウンロードしてコマンドラインですぐにインストールできます。Web サイトのルートフォルダでターミナルを開き、次を実行します。

```bash
# 1) ウェブサイトごとに 1 回だけ：GP247 ライブラリに接続するための API License（無料）を登録
php artisan gp247:ext-register-license

# 2) ライブラリからプラグインをダウンロードしてインストール
php artisan gp247:ext-install --type=plugin --key=ProductRating
```

- 手順 1 の前に、`.env` の `APP_URL` が Web サイトの**実際のドメイン**になっていること（`http://localhost` のままでないこと）を確認してください。ライセンスはこのドメインに紐付けられます。
- インストール後、プラグインは**有効化済み**となり、キャッシュも自動的に更新されるため、管理画面で追加の操作は不要です。
- コマンドは `gp247.json` で宣言された条件（core のバージョン、composer パッケージ、依存プラグイン）を自動で確認します。不足があれば停止し、何が足りないかを明示します。
- このプラグインには `gp247/shop` パッケージのインストールが必要です。不足している場合、コマンドは停止して通知します。
- `app/GP247/Plugins/ProductRating` フォルダがすでにサーバー上にある場合（手動でコピーした、またはインストーラーに同梱されていた場合）、コマンドは再ダウンロードせず**その場でインストール**します。
- プラグインがすでにインストール済みの場合、コマンドは拒否します。新しいバージョンにするには `php artisan gp247:ext-update --type=plugin --key=ProductRating` を実行します。
- コマンドの末尾に `--json` を付けると、機械可読形式で結果を受け取れます（スクリプト・CI 向け）。
- このコマンドは上記の手順 1〜2 の代わりになります。インストール後の手順はそのままです。新しいメニューをクリックして「ページが見つかりません」というエラーが出た場合は、手順 3 と同様に `php artisan optimize:clear` を実行してください。その後、手順 4（2 つの新しいメニュー項目）と手順 5（商品ページの**「商品レビュー」**ブロック）のとおり確認します。
- 詳細：[プラグイン・テンプレートのインストールガイド](https://github.com/gp247net/gp247-docs/blob/main/extension/install-extension.md) · [コマンドリファレンス](https://github.com/gp247net/gp247-docs/blob/main/system/command-line-reference.md)。

## 設定

**Plugins** を開き、Product Rating & Review の行にある**設定**ボタンをクリックします。

| 項目 | 既定値 | 意味 |
| --- | --- | --- |
| 購入必須 | オン | その商品を含む注文があるお客様のみレビューできます。 |
| すぐに表示 | オフ | オフ：新しいレビューはあなたの承認が必要です。オン：すぐに表示されます。 |
| 写真の添付を許可 | オフ | お客様が商品の実物写真を添付できるようにします。 |
| レビューごとの写真枚数 | 3 | 1 件のレビューに添付できる写真の最大枚数です。 |
| 評価スケール | 5 つ星 | 5 つ星または 10 つ星を選びます。 |

Web サイトに**複数のストア**がある場合は、ストアごとに個別に設定できます。上部の
選択欄でストアを選んでから調整してください。何も調整していないストアは、共通の
既定設定を使用します。

## お客様のレビュー方法

1. お客様が商品ページを開き、**商品レビュー**ブロックまでスクロールします。
2. ログインしていない場合、入力欄の代わりに**ログイン**ボタンが表示されます。
3. お客様は星の数を選び、コメントを書き（任意）、**レビューを送信**をクリックします。
4. 審査が必要な設定にしている場合、お客様には受け付けた旨が通知され、レビューは
   あなたの審査画面で待機状態になります。
5. 送信後、お客様には自分のレビューが**編集**と**レビューを取り下げる**の 2 つの
   ボタン付きで再表示されます。

購入済みのお客様によるレビューには**「購入済み」**ラベルが付き、閲覧者からの信頼が
高まります。

## レビューの管理

**Catalog → 商品レビュー**を開きます。状態（審査待ち／承認済み／却下）やストアで
絞り込み、内容やお客様名で検索できます。

**商品名**をクリックすると、その商品のページが Web サイト上で（新しいタブで）開きます。
承認済みのレビューには、そのレビューへ直接移動する**サイトで表示**リンクも付いており、
購入者からどのように見えるかを確認できます。

各レビューに対して、次の 4 つの操作ができます。

- **承認** — レビューが Web サイトに表示され、平均評価に計算されます。
- **却下** — レビューは公開されなくなります。用意されたリストから**理由の選択が
  必須**です（下記参照）。
- **公開返信** — あなたの返信がそのレビューのすぐ下に表示され、商品を見る全員が
  閲覧できます。1 件のレビューにつき返信は 1 件で、編集できます。内容を空にして
  保存すると返信は取り下げられます。
- **削除** — 完全に削除します。**システム管理者アカウントのみ実行できます**。
  ショップオーナーとスタッフにはこのボタンは表示されません。

### ショップオーナーがレビューを削除できない理由

ショップが自分への否定的なレビューを削除できてしまうと、星の評価は広告にすぎなく
なり、購入者は信頼できなくなります。2 つの主要な規制当局がこの点を直接定めています。

- **米国（FTC、2024 年 10 月 21 日施行）：** すべてのレビューを表示しているかのように
  レビュー欄を見せながら、**評価が低い、または否定的であるという理由で**レビューを
  ひそかに差し止めてはなりません。基準が肯定・否定を問わず**すべてのレビューに
  等しく**適用される場合は、削除しても問題ありません。
- **欧州（指令 2019/2161、2022 年 5 月 28 日適用）：** 商品を宣伝する目的で消費者の
  レビューを偽って表示することを禁じています。

そのため、このプラグインは次のように設計されています。レビューを取り下げることは
できますが、固定のリストから**理由を示す**必要があり、**すべての判断がログに記録**
されます（誰が、いつ、どの理由で）。否定的なレビューに対してあなたが使うべきツールは
**公開返信**であり、削除ではありません。

却下理由のリスト：スパムまたは偽レビュー · 侮辱・ヘイト · 他人の個人情報を含む ·
違法な内容 · 利益相反 · この商品に関する内容ではない。「評価が低い」という理由は
意図的に**ありません**。

## 統計

**Report → レビュー統計**を開きます。この画面では次の情報を確認できます。

- レビューの総数、表示中の件数、審査待ちの件数、平均評価。
- **ショップ別**の比較表（Web サイトに複数のストアや複数の販売者がある場合に
  便利です）。
- 評価の分布グラフ：5 つ星、4 つ星…のレビューがそれぞれ何件あるか。
- 最も多くレビューされた商品の一覧と、その平均評価。

平均評価は**承認済みのレビューのみ**で計算されます。審査待ちや却下されたレビューが
外部に表示される評価に影響することはありません。

## テーマ（テーマ制作者向け）

**通常は何もする必要はありません。** レビューブロックは自動的に表示されます。
`gp247/shop` が提供する商品詳細ページにはあらかじめ**拡張ポイント**があり、
プラグインはインストールされるとそこに描画されます。このページを基に作られた
テーマ（GP247Front を含む）は、何も変更せずにレビューブロックを利用できます。

テーマが商品詳細ページを独自に書き直している場合に限り、表示したい位置に拡張
ポイントを追加する必要があります。

```blade
{!! gp247_render_plugin_hook('shop_product_detail_bottom', ['product' => $product]) !!}
```

この 1 行は、レビュープラグインに限らず、現在および今後の**すべてのプラグイン**に
対応します。テーマがこれを呼び出さない場合は、単に何も表示されません。

プラグインを変更せずに表示方法を変えたい場合は、テーマフォルダ内に
`livewire/productrating_review-box.blade.php` ファイルを作成します。
システムはあなたのファイルを優先し、プラグイン内の元のファイルは更新時にもそのまま
保持されます。

## ショップページへのレビュー表示（開発者向け）

各レビューは**2 つ**のストアを記録します。お客様がレビューを書いたストアと、**商品を
販売するストア**です。単一ストアの Web サイトでは、この 2 つの値は同じです。
複数の販売者が 1 つのドメインを共有するマーケットプレイス型では異なり、ショップ
ページでグループ化の基準にすべきなのは商品を販売するストアのほうです。

ショップページ用の既製ブロック（平均評価、星の数による絞り込み、レビューされた
商品の一覧とコメントを含む）：

```blade
@livewire('gp247-productrating-front::store-rating-box', ['sellerStoreId' => $store->id])
```

独自に画面を作りたい場合は、次の関数を呼び出します。

```php
// ショップ全体の集計：合計、平均、星ごとの分布。
$summary = gp247_product_rating_store_summary($sellerStoreId);

// ショップが評価されている商品（レビューの多い順）。
$products = gp247_product_rating_store_products($sellerStoreId, limit: 20, offset: 0);

// 商品グリッド全体を 1 回の呼び出しで取得（繰り返し呼び出しによる遅延なし）。
$map = gp247_product_rating_bulk_summary($productIds, $sellerStoreId);

// 1 商品の集計（商品ページと同じもの）。
$summary = gp247_product_rating_summary($productId, $storeId);
```

いずれも**承認済み**のレビューのみを集計します。

## 条件と制約（操作する前に理解してください）

### お客様がレビューを送信するとき

- **ログインが必須です** — これは固定のルールで、オフにはできません。匿名レビューは
  スパムの入り口になります。
- **評価（星）は必須で、文字だけでは送信できません** — 評価は平均評価を生み出す
  ものであり、評価がなければコメントは検討中の購入者の役に立ちません。
- **評価は選択したスケール内である必要があります**（1〜5 または 1〜10）。システムは
  画面上だけでなくサーバー側でも再確認します。
- **コメントは最大 2,000 文字です。**
- **1 件の注文につきレビューは 1 件です** — 2 回購入すれば 2 件のレビューを書けますが、
  1 回の購入が 2 件の評価になることはありません。これは、1 人が商品の評価を不正に
  上げたり下げたりすることを防ぐための仕組みです。
- **「購入必須」をオンにしている場合**、お客様にはその商品を含む注文が必要です。
  **キャンセル**または**失敗**した注文は数えません — 数えてしまうと、注文してすぐに
  キャンセルするだけでレビューできてしまいます。
- **写真：** JPG、PNG、WEBP のみ受け付けます。1 枚あたり最大 2 MB、枚数はあなたの
  設定に従います。

### お客様が自分のレビューを編集・取り下げるとき

- **編集すると審査待ちの状態に戻ります**（「すぐに表示」をオンにしている場合を除く）
  — そうしないと、承認済みのレビューが誰にも再確認されないまま別の内容に書き換え
  られてしまう可能性があります。
- **取り下げた後、その注文について再びレビューを書くことはできません** — 内容と写真は
  実際に削除されますが、その注文のレビュー枠は使用済みとして扱われます。そうしないと、
  取り下げて書き直すことが無制限の再評価手段になってしまいます。

### あなたが審査するとき

- **却下には固定リストからの理由の選択が必須です**。選択しないとシステムは取り下げを
  許可しません。空欄の理由や独自に作った理由はすべて拒否されます。
- **公開返信は最大 1,000 文字です**。また、返信はそのレビューが表示されるかどうかを
  **変更しません**。
- **レビューを削除できるのはシステム管理者のみです**。ショップオーナーとスタッフは
  承認、却下、返信のみ行えます。

## よくある質問（Q&A）

**質問 1：インストール後、メニューをクリックすると「ページが見つかりません」というエラーが出ます。**

→ インストールの手順 3 で `php artisan optimize:clear` を実行していません。このコマンドを再度実行してから、ページを再読み込みしてください。

**質問 2：商品ページにレビューブロックがまったく表示されません。**

→ Plugins メニューでプラグインが有効になっているか確認してください。Web サイトが GP247Front 以外のテーマを使っている場合は、「レビューブロックを他のテーマに追加する」項目のコードを追加する必要があります。

**質問 3：購入していなくても、どのお客様でもレビューできるようにしたいです。**

→ プラグインの設定を開き、「購入必須」をオフにします。その場合、お客様は 1 つの商品につき 1 件のレビューを書けます。

**質問 4：レビューの削除ボタンが表示されないのはなぜですか？**

→ あなたのアカウントがシステム管理者ではないためです。ショップオーナーとスタッフは承認、却下、返信のみ行えます。「ショップオーナーがレビューを削除できない理由」の項目をご覧ください。

**質問 5：事実と異なる 1 つ星のレビューがあります。どうすればよいですか？**

→ 「公開返信」ボタンを使い、そのレビューのすぐ下で正しい情報を示してください。内容が用意された却下理由（スパム、侮辱、無関係な内容…）のいずれかに該当する場合は、理由を付けて却下します。評価が低いという理由だけで取り下げることはできません。

**質問 6：お客様が同じ商品を繰り返し購入した場合、何回レビューできますか？**

→ 1 件の注文につき 1 回です。3 回購入すれば 3 件のレビューを書けます。それは 3 回の実際の体験だからです。

**質問 7：審査待ちのレビューで星の評価が下がることはありますか？**

→ いいえ。平均評価は承認済みのレビューのみで計算されます。

**質問 8：Web サイトに複数のストアがあります。設定は共通ですか？**

→ ストアごとに個別に設定できます。何も設定していないストアは、共通の既定設定を使用します。

**質問 9：プラグインを新しいバージョンに更新すると、設定やデータは失われますか？**

→ いいえ。あなたの選択内容とすべてのレビューは保持されます。お客様が送った写真もプラグインフォルダの外に保存されるため、上書きされません。

**質問 10：お客様がプライバシー上の理由でレビューの削除を求めてきた場合は？**

→ お客様自身が商品ページで「レビューを取り下げる」をクリックできます。内容と写真は実際に削除されます。痕跡まで完全に消す必要がある場合は、システム管理者に削除ボタンを使うよう依頼してください。
